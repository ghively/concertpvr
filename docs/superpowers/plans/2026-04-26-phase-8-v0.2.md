## Cross-cutting guardrails (apply to every task in this phase)

**Locked design constraints — do not deviate:**

1. **No `Field(...)` weakening** to silence type checkers. If mypy complains, use `# type: ignore[call-arg]` or the `pydantic.mypy` plugin (already enabled).
2. **No test rewriting** that changes what the spec asserts. If a test fails, fix the implementation, not the assertion (unless the test itself is wrong — flag and explain).
3. **No mypy strictness relaxation.** Strict stays strict.
4. **Pydantic validators on `SettingsPatch` only**, never on `SettingsRead`. Bad data already in the DB must still parse on read.
5. **Pagination defaults: `limit=None` (unlimited).** Setting a default of 100 silently breaks the frontend. Stay backward-compatible.
6. **Lifespan ordering:** `Base.metadata.create_all` → orphan scan → `register_app` → `scheduler.start()` → `rehydrate_from_db`. If you flip orphan-scan-vs-rehydrate, scheduled jobs could fire before the scan and create rows that get nuked.
7. **Confirm dialogs use `useConfirm()`**, never browser `confirm()`.
8. **Commit format:** every commit `git -c gpg.format=openpgp -c commit.gpgsign=false commit -m "..."`.
9. **Use:** `./.venv/Scripts/python.exe -m pytest ...` for tests. `cd frontend && npm run typecheck && npm run build` for frontend.

- [ ] **Step 1: Create `src/concertpvr/orphan_recovery.py`**

```python
"""On startup, mark any Recording rows still in 'recording' state as 'interrupted'.

Spec §9 promises this resilience guarantee. If the app crashes mid-record, the row
stays `recording` forever and the UI shows it as live. This module fixes that
on every cold start. Safe because `register_app` runs after this — the recorder
pool is empty at startup, so any `status='recording'` row is a real orphan.
"""

from __future__ import annotations

import datetime as _dt
import logging

from sqlalchemy import select

from concertpvr.db import Database
from concertpvr.models import Recording

logger = logging.getLogger(__name__)


def mark_interrupted_on_startup(db: Database) -> int:
    """Mark all recordings still in 'recording' state as 'interrupted'.

    Returns count of rows updated.
    """
    count = 0
    with db.session() as s:
        rows = list(s.scalars(select(Recording).where(Recording.status == "recording")))
        now = _dt.datetime.now(_dt.UTC)
        for rec in rows:
            rec.status = "interrupted"
            if rec.ended_at is None:
                rec.ended_at = now
            count += 1
    if count:
        logger.warning("orphan_recovery: marked %d recording(s) as interrupted", count)
    return count
```
